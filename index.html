📌 How the Two Stacks Work

  • Visit Push current → Back Stack · Clear Forward Stack · Set new page as current
  • Back Push current → Forward Stack · Pop from Back Stack → make current
  • Forward Push current → Back Stack · Pop from Forward Stack → make current
  • Home / Reset Clear both stacks and return to blank page
